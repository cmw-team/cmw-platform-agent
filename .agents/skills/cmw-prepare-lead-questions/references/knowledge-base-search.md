# Поиск по базе знаний Comindware

## Tool

Используй MCP-tool `get_knowledge_base_articles`.

Не используй `ask_comindware` как источник подтверждений: он возвращает
синтезированный разговорный ответ, а не набор исходных статей.

## Версия платформы

Используй значение по умолчанию для `product_version`, объявленное в схеме MCP-tool.

Если пользователь явно указал версию Comindware Platform, передай её в
`product_version` в формате, который принимает схема инструмента. Явно указанная
пользователем версия имеет приоритет над значением по умолчанию из схемы.

Не определяй версию по текущей дате и не заменяй явно указанную пользователем
версию более новой.

Пример:

```json
{
  "query": "маршруты согласования договоров интеграция с внешней системой",
  "top_k": 5
}
```

## Когда искать

Ищи в базе знаний, если запрос лида содержит:

- конкретный бизнес-процесс;
- интеграцию;
- документы, маршруты, роли, формы или задачи;
- требование, которое может повлиять на содержательность уточняющих вопросов.

Не выполняй поиск только для того, чтобы упомянуть функции Comindware.

## Как использовать результат

- Используй статьи для понимания терминов и возможных ограничений.
- Формулируй вопросы, которые проясняют требования клиента.
- Не превращай итог в описание продукта.
- Не утверждай реализуемость без достаточного подтверждения.
- Не показывай ссылки и выдержки в финальной десятке вопросов.

Если подходящих статей нет, не додумывай возможности платформы. Сформулируй
нейтральный вопрос об ожидаемом результате или технических ограничениях.
