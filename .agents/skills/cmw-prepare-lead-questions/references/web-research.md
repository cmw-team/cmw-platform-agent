# Веб-исследование компании

## Tool

Используй tool `web_search`.

Формат вызова:

```json
{"query": "<один короткий поисковый запрос>"}
```

Успешный результат находится в `data.results`. Для каждого результата используй
поля `title`, `url` и `content`. Это поисковые фрагменты, а не полный текст
страницы.

## Цель

Получить минимум сведений, необходимых для умеренной адаптации вопросов:

- официальное название и сайт;
- основное направление деятельности;
- география и тип клиентов, если это достоверно;
- публично описанные продукты, услуги или бизнес-направления;
- отраслевая терминология, релевантная запросу.

## Порядок вызовов

Начинай с одного узкого запроса, объединив все доступные идентификаторы:

```text
"{ИНН}" "{название компании}" "{корпоративный домен}" официальный сайт
```

Не добавляй отсутствующие идентификаторы. Если известно только название
компании, поиск по одному названию допустим:

```text
"{название компании}" официальный сайт
```

По `data.results` найди результат, который соответствует идентификаторам и
вероятнее всего ведёт на официальный сайт. Если официальный сайт неоднозначен,
разрешён один дополнительный уточняющий вызов, например:

```json
{"query": "site:<предполагаемый домен> <название компании> деятельность"}
```

Не проводи глубокое исследование и не делай дополнительные вызовы, если
базовых сведений достаточно для адаптации 10 вопросов. Если `web_search`
вернул `success: false`, продолжай с доступными данными или задай уточнение,
когда без идентификации компании работа невозможна.

## Правила качества

1. Предпочитай официальный сайт.
2. Не считай поле `content` достаточным подтверждением спорного факта.
3. Если найдено несколько одноимённых компаний, попроси домен, ИНН или город.
4. Не используй неподтверждённые проблемы компании как факты.
5. Не перегружай вопросы найденной терминологией.

## Конфиденциальность

В поисковый запрос нельзя включать:

- текст транскрипта;
- CRM-комментарии;
- личные email и телефоны;
- бюджет;
- имена непубличных участников сделки;
- другие непубличные сведения.
